# Angelina | Premium Visual Concepts

[English](#english) | [Русский](#русский)

---

## English

Personal portfolio website of **Angelina** — neurophotographer and AI creator. The site showcases premium visual concepts for brands including virtual models, beauty shoots, realistic neurophotoshoots, fantasy characters, and commercial campaigns created using advanced AI generation, without the need for physical studios or photographers.

### Features
* **Bilingual Support:** Smooth toggle between English and Russian (RU/EN).
* **Interactive Showcase Slider:** Interactive slider comparing raw camera RAW source images with final retouched commercial art.
* **Virtual Models Showcase:** Dynamic switcher to view apparel and jewelry on different digital models (Mia & Eva).
* **Interactive Portfolio Grid:** Filter cases by categories: Fashion, Beauty, Neurophotoshoots, and Fantasy/Games.
* **Modern UI/UX:** Responsive design powered by Tailwind CSS, featuring glassmorphism, custom liquid mouse-glow animations, and image lightboxes.
* **Contact Form:** Fully functional popup modal email form powered by FormSubmit.

### Technologies
* HTML5 / CSS3
* Tailwind CSS (via CDN)
* Vanilla JavaScript (ES6+)
* FormSubmit (for contact form processing)

## Русский

Персональный сайт-портфолио **Ангелины** — нейрофотографа и AI-креатора. Сайт представляет премиальный визуал для брендов: виртуальные модели, бьюти-съемка, реалистичные нейрофотосессии, фэнтези-арт и коммерческие кампейны, созданные с помощью нейросетей без использования студий и услуг классических фотографов.

### Возможности сайта
* **Двуязычный интерфейс:** Мгновенное переключение языков (RU/EN) для всех элементов интерфейса, включая всплывающие окна и подсказки.
* **Интерактивный слайдер сравнения:** Слайдер сравнения «до/после» (сырой RAW-кадр против финального коммерческого арта).
* **Презентация виртуальных моделей:** Динамический переключатель для демонстрации товаров на готовых цифровых моделях (Мия и Ева).
* **Фильтрация кейсов:** Удобный интерактивный каталог работ с сортировкой по категориям (Фэшн, Косметика, Нейрофотосессии, Фэнтези).
* **Современный UI/UX:** Адаптивный дизайн с эффектом стеклянного размытия (glassmorphism), интерактивными микро-анимациями и эффектом интерактивного градиентного свечения за курсором.
* **Контактная форма:** Всплывающее модальное окно обратной связи на базе интеграции с сервисом FormSubmit.

### Технологии
* HTML5 / CSS3
* Tailwind CSS (подключен через CDN)
* Чистый JavaScript (ES6+)
* Интеграция с FormSubmit (обработка заявок на почту)
